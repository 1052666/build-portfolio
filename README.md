# BUILD / 个人作品集

一份以黑白与朱红为视觉语言的静态作品集，展示 Agent、开源协作、GEO 与公益 AI 实践。个人信息已脱敏。

## 内容与交互

- 六个项目展区与完整项目档案
- 可拖动、可暂停的立体网格
- 技术能力展开、成长轨迹与完整履历
- 脱敏 PNG 简历下载
- 响应式布局、键盘操作及减少动态效果支持

## 本地浏览

直接用浏览器打开 `index.html`，或使用任意静态文件服务器。无依赖、无构建步骤、无第三方在线资源。

## 部署

使用 GitHub Pages，从默认分支的根目录发布。`.nojekyll` 保留纯静态文件行为。

## 文件

- `index.html`：首页、项目详情与完整脱敏履历
- `style.css`：视觉样式与响应式布局
- `app.js`：交互及动态效果
- `assets/resume.png`：脱敏简历长图
